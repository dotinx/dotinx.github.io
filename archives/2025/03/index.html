这篇文档仅为对我自己所持有公钥的介绍

不构成其他建议

我当前使用的 PGP 公钥为 E768 8A8E D1E6 3657 42D8 E762 81EB 0DDD DDDD DDDD。

该公钥同时发布在如下站点：

  • OpenPGP Keyserver
  • Keybase
  • This Blog

如果有出入，请以 keys.openpgp.org 上的公钥为准。

以下内容的时效性较差，可能与现在的实际情况有所出入。

Last Update: 2026-02-12

如果你导入了我的公钥的话，若使用 gpg --keyid-format long -k 查看，大概是这个样子。

其中，0x28C5A23A, 0x59E92BE9, 0x83748F7C 三个子密钥为我的J3R180智能卡上的密钥，因为我的懒惰所以这是使用的 SmartPGP 智能卡应用的默认算法。

其次，唯一的具有双用途的密钥 0x5D670D21 是用于 Keybase 的密钥。它的私钥存储于 Keybase 宣称的客户端加密中。它的有效期较短，且比较容易被我吊销。

再次，三个椭圆曲线密钥是备用密钥。

最后，主密钥仅保留了 Certify 用途，且透过多种方法存储于与网路隔离的存储中。

对了，因为我是 1Password 的狗，我的 Git 提交目前是使用我的 SSH 密钥签署的。密钥指纹为 SHA256:oEFbclBdeqw4M09C3hfnDej0ioZdzZW6BKxsZH6quX8。

若有加密通信需求的话，还请使用 GPG 进行通讯。

或 Matrix，但是我不常看。

（或许，使用 Keybase 也可以，前提是你能接受它的虚假）
